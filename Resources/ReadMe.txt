A “Personal Projects” app
You could build an app that keeps track of your coding projects.
Each project could have:
Project
├── name
├── language
├── description
├── status
├── date started
├── last worked on
├── notes
└── favourite
Then progressively add:
1. List of projects
2. Add project
3. Edit project
4. Delete project
5. Search
6. Filter
7. Sort
8. Detail view
9. Navigation
10. Persistence
11. Error handling
12. Sheets
13. Alerts
14. Swipe actions
15. Accessibility
16. Share/export
17. Settings
